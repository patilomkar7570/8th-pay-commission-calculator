# 8th Pay Commission Fitment & Salary Calculator

A modern, responsive, light-mode web application designed for Central and State Government employees to calculate revised salaries under the upcoming **8th Pay Commission (CPC)**.

## 🚀 Features

- **Revised Basic-Centric Calculations**: All subsequent allowances (DA, HRA, Transport Allowance, etc.) and deductions are computed directly from the **Revised 8th CPC Basic Pay** (or fixed amounts).
- **Numbers vs. Percentage Toggle**: Above each component, easily switch between **`% of New Basic`** and **`₹ In Numbers`**.
- **Interactive `+` Custom Tab**: Add custom allowances (Plus) or deductions (Minus) on the fly with live calculation.
- **One-Click PDF Salary Statement**: Automatically generates and downloads a clean, professional PDF salary statement with full comparative breakdown.
- **Print Friendly**: Built-in direct print support with print-optimized styling.
- **Light & Accessible UI**: Clean layout built with standard HTML5, CSS3, and modern Vanilla JavaScript without bloated frameworks.
